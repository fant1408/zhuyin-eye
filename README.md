# 眼睛注音板

給自閉症兒童在 **iPad mini 7（A17 Pro）** 上用眼睛選注音符號打字的網頁工具。孩子照「聲母 → 介音 → 韻母 → 聲調」一步一步拼，拼完選國字（或只打注音），iPad 會唸出來。

## 三種輸入方式

| 方式 | 適合 | 需要 |
|---|---|---|
| **觸控／iPad 內建眼動追蹤**（預設，推薦） | 大多數孩子 | iPadOS 18 以上，打開內建「眼動追蹤」和「停留控制」。網頁只要收到「點一下」，所以手指、外接開關也都能用 |
| 游標停留 | 頭控滑鼠、一般滑鼠、會移動游標的眼動裝置 | 游標停在格子上超過設定秒數就選取 |
| 本程式相機眼控 | 想要更兒童化的校正流程，或內建眼動追蹤不適合時 | 必須放在自己的 **https 網址**（見下方「自己架站」）。Claude 的預覽頁面不能開相機 |

## iPad 要先設定的地方

1. **眼動追蹤**：設定 › 輔助使用 › 眼動追蹤 → 開啟，跟著圓點完成校正，確認「停留控制」是開著的。
2. **中文語音**：設定 › 輔助使用 › 朗讀內容 › 聲音 › 中文 → 下載「美佳（台灣）」的加強版聲音，唸起來比較自然。
3. **引導使用模式**（建議）：設定 › 輔助使用 › 引導使用模式 → 開啟。打開本工具後連按三下頂端按鈕，孩子就不會跳出去。
4. iPad 放在穩定的支架上，距離臉 30–45 公分，臉在畫面中間，光線從正面來。

> 選單名稱是依據 iPadOS 18 的一般寫法。Apple 官方頁面在製作時連不上，所以這部分沒有逐字核對，iPad 上的實際名稱可能略有不同。

## 怎麼打字

- 第一步選聲母組（例如 ㄅㄆㄇㄈ），再選符號；沒有聲母的字（例如「我」ㄨㄛˇ）選「沒有聲母」。
- 第二步選介音或韻母。打開「拼音輔助」時，拼不出來的符號會變淡、不能選（例如 ㄐ 後面不能接 ㄨ）。
- 第三步選聲調，每個聲調格子會顯示例字（ㄇㄚ：媽、麻、馬、罵、嗎）。
- 第四步選國字，字下面有提示詞（媽 → 媽媽、麻 → 麻煩），避免選到同音字。
- 右邊（直放時在下面）三顆固定鍵：**退回**（每按一次退一步，可以一直看著連續退）、**唸出來**、**更多**（標點、空格、常用句、全部清除、休息）。
- 上方打字區和拼音格是「休息區」，眼睛看這裡不會選到東西。

## 家長設定

在鍵盤畫面**按住右上角的齒輪 1 秒**才會打開。孩子用眼睛只會「點一下」，所以不會誤開。可以調整：

- 停留時間 0.6–3 秒（預設 1.2 秒）、相機眼控的追蹤方式（看眼睛／看頭部轉向）、游標穩定度、校正點數
- 打出國字或只打注音、拼音輔助、聯想下一個字、國字上方顯示注音
- 符號和國字要不要唸出來、提示音、說話速度
- 字的大小、低刺激模式（顏色變淡、沒有動畫）
- 常用句（最多 8 句，選到會直接唸出來）

設定和打出來的字只存在這台 iPad 的瀏覽器裡，不會上傳。

## 自己架站（要用相機眼控時）

相機只能在 https 網址使用。執行 `python3 tools/build.py` 會產生 `docs/` 和 `zhuyin-eye-site.zip`，把它放到任何靜態網站服務就可以：

- **Netlify Drop**：把 `docs` 資料夾拖到 app.netlify.com/drop。
- **GitHub Pages**：把整個專案推到 repo，在 Settings › Pages 選「Deploy from a branch」→ `main` / `/docs`。
- **Cloudflare Pages**：上傳 `docs/`。

用 iPad 的 Safari 打開網址 → 分享 › 加入主畫面，之後從主畫面圖示打開就是全螢幕，也能離線使用。第一次載入相機眼控模型約 15 MB，之後會留在快取裡。

### 離線使用

| 打開方式 | 沒有網路時 |
|---|---|
| Claude 的 Artifact 連結 | **不能用**：每次打開都要連到 claude.ai 並登入。已經打開的畫面在斷網後還能繼續打字（字典和程式都已載入），但重新整理或被 Safari 關掉就打不開 |
| 自己架站＋加入主畫面 | **可以用**：第一次連網打開時會把鍵盤、字典、字型和相機眼控模型（共約 20 MB）存進 iPad，之後沒網路也能開 |

自架版離線前請確認：

1. 用 Safari 打開網址 → 分享 › 加入主畫面，**從主畫面圖示**打開一次，保持連網 2–3 分鐘。
2. 按住齒輪進「家長設定」，「離線使用」顯示「✓ 已可以離線使用，包含相機眼控」就完成了。
3. 之後改版只要連網打開一次，下次打開就是新版。模型不會重新下載。

離線時也能用的部分：iPad 內建眼動追蹤（在 iPad 上運算）和中文語音（用 iPad 內建的聲音）。如果某個加強版聲音還沒下載，iPad 會改用預設聲音。

### 相機眼控怎麼運作

1. MediaPipe Face Landmarker 在 iPad 上即時找出臉部 478 個點，以及虹膜位置、眼球轉向和頭的角度。在 Apple 裝置上固定用 CPU 執行，因為 Safari 的 GPU 模式有輸出錯亂的回報。
2. 校正時孩子看著 5 或 9 個慢慢縮小的黃色圓點，程式用加權脊迴歸學會「這個孩子的眼睛特徵」對應到「畫面哪裡」。
3. 用 One Euro 濾波讓游標穩定，不會抖。眨眼時會暫停，不會誤選。
4. 每次用眼睛選到格子，就把格子中心當成新的校正資料，慢慢自動修正偏移。選完立刻按「退回」的那次會被當成選錯，不拿來學。
5. 剛選過的位置要先把眼睛移開才會再選，換頁時不會連續誤選。
6. 校正結果分別存在橫放、直放以及看眼睛、看頭部的組合裡。iPad 轉向後會請你重新校正。

## 設計依據

| 決定 | 依據 | 可信度 |
|---|---|---|
| 預設停留 1.2 秒，可調 0.6–3 秒 | 成人新手的固定停留時間通常是 450–1000 ms，練習 10 次後可降到約 280 ms（Majaranta 等，CHI 2009，doi:10.1145/1518701.1518758）。兒童沒有找到明確數值，所以先放寬，再依孩子的表現往下調 | 成人：可能正確；兒童：不確定 |
| 每頁最多 8 格、格子之間留縫 | 眼控選取建議目標至少約 2° 視角並保留間距（Glasgow eprints 346375）。iPad mini 橫放每格約 4×5 公分 | 不確定（找不到兒童專用的數值） |
| 格子位置固定，拼不出來的變淡、不移除 | 固定的空間位置和用顏色分群能幫助在溝通板上找符號（Light 等 2019，AAC 版面設計綜述） | 可能正確 |
| 聲母藍、介音綠、韻母黃、聲調紫，低彩度；可切換低刺激 | 同上。背景色在小螢幕上不一定有幫助，所以只用柔和的類別色 | 可能正確 |
| 不閃爍、沒有倒數、沒有失敗音效 | 一般感官友善設計原則 | 原則性建議 |
| 練習要有耐心 | 1–15 歲第一次用眼控的孩子，速度約 5 個月後進步，準確度要 15–20 個月（Borgestig 等 2016，doi:10.1080/10400435.2015.1092182） | 可能正確 |

## 已知限制

- 相機眼控沒有在真正的 iPad mini 7 上測試過（開發環境只有模擬鏡頭）。實際準確度要看光線、距離、孩子的配合度。不穩定時請改用 iPad 內建眼動追蹤。
- 單獨唸注音符號是借用同音字（例如 ㄅ 唸「玻」），少數符號（ㄝ、ㄥ）聽起來可能不夠標準。
- 字典來自新酷音（libchewing）詞庫，依使用頻率排序，每個音最多 12 個字，並過濾成 Big5 字元，但仍可能留有少數罕用字。
- 「唸出來」只打注音時，是用同音最常用字給語音引擎唸。少數破音字可能唸錯聲調。

## 檔案

```
index.html          主頁面（樣式、版面、設定畫面）
app.js              鍵盤流程、停留選取、語音
gaze.js             相機眼控（特徵、校正、迴歸、濾波）
data/               注音字典與產生腳本（build_dict.py）
vendor/mediapipe/   MediaPipe Tasks Vision 0.10.35 與 face_landmarker 模型
tools/build.py      產生可以自己架站的 docs/ 與 zip
tools/make_font.py  產生本機字型子集（粉圓改名版）
docs/               打包好的網站（GitHub Pages 用）
test/               Playwright 測試（e2e.js、offline.js）
```
